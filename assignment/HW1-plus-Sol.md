## Exercise 3

The division `x = y / z` is reported if `IN[n](z)` is `0`, `≤0`, `≥0` or `⊤` (the values that may
contain `0`). It is not reported for `−`, `+`, `≠0` or `⊥`.

The analysis is a may analysis: every abstract value describes the set of values the variable can
take at run time, so `0 ∈ γ(IN[n](z))` means that some execution can divide by zero. Reporting only
when `IN[n](z) = 0` would turn it into a must analysis (a division that always divides by zero) and
would miss real possible divisions by zero.

## Exercise 4

Control-flow graph (conditions are not refined by the analysis):

```
1: i = 0
2: if (i < n) goto 3 else goto 4
3: i = i + 1; goto 2
4: k = i + 1; j = n / k; r = n / i; return j + r
```

`IN[1] = {n: ⊤}`.

### HW1 lattice (`⊥, −, 0, +, ⊤`)

| pass | `IN[2](i)` | `OUT[2](i)` | `IN[3](i)` | `OUT[3](i)` | `IN[4](i)` | `OUT[4](k)` |
|---|---|---|---|---|---|---|
| 1 | `0` | `0` | `0` | `+` | `0` | `+` |
| 2 | `⊤` | `⊤` | `⊤` | `⊤` | `⊤` | `⊤` |
| 3 | `⊤` | `⊤` | `⊤` | `⊤` | `⊤` | `⊤` |

Stable state:

| node | `IN(i)` | `OUT(i)` | `IN(k)` | `OUT(k)` |
|---|---|---|---|---|
| 1 | `⊥` | `0` | `⊥` | `⊥` |
| 2 | `⊤` | `⊤` | `⊥` | `⊥` |
| 3 | `⊤` | `⊤` | `⊥` | `⊥` |
| 4 | `⊤` | `⊤` | `⊥` | `⊤` |

Reported divisions: `j = n / k` and `r = n / i` (both, since `k = i = ⊤`).

### Extended lattice (`⊥, −, 0, +, ≤0, ≥0, ≠0, ⊤`)

| pass | `IN[2](i)` | `OUT[2](i)` | `IN[3](i)` | `OUT[3](i)` | `IN[4](i)` | `OUT[4](k)` |
|---|---|---|---|---|---|---|
| 1 | `0` | `0` | `0` | `+` | `0` | `+` |
| 2 | `≥0` | `≥0` | `≥0` | `+` | `≥0` | `+` |
| 3 | `≥0` | `≥0` | `≥0` | `+` | `≥0` | `+` |

Stable state:

| node | `IN(i)` | `OUT(i)` | `IN(k)` | `OUT(k)` |
|---|---|---|---|---|
| 1 | `⊥` | `0` | `⊥` | `⊥` |
| 2 | `≥0` | `≥0` | `⊥` | `⊥` |
| 3 | `≥0` | `+` | `⊥` | `⊥` |
| 4 | `≥0` | `≥0` | `⊥` | `+` |

Reported divisions: only `r = n / i`.

- `r = n / i` is a real possible division by zero: if `n ≤ 0` the loop is not executed, so `i = 0`.
- `j = n / k` is not possible: `k = i + 1` with `i ≥ 0`, so `k ≥ 1`. HW1 reports it only because the
  five-value lattice merges `i = 0` and `i = +` into `⊤`.
